# Контур

Небольшой трекер задач на React. Самостоятельный учебный проект FGIp07. Разработка выполнена в Codex.

[Адрес приложения после публикации](https://denis-zag.gitverse.site/fgip07-react-kontur/) · [Исходное объявление](https://www.fl.ru/projects/5026526/todo-prilojenie-na-react.html)

## Возможности

React; создание, редактирование и удаление задач; три статуса на канбан-доске и список; поиск и приоритеты; сроки; управление с клавиатуры; локальное сохранение; JSON-копия.

## Быстрый запуск

Готовая сборка находится в `public/`. Для запуска нужен Node.js 22 или новее:

```text
node preview.mjs
```

Либо дважды нажмите `start.cmd` в Windows. Откройте http://127.0.0.1:8080/ . Для запуска готовой сборки устанавливать библиотеки не нужно. Чтобы открыть три проекта одновременно, задайте каждому свой PORT.

## Сборка из исходников

```text
npm ci
npm run build
npm start
```

React 19.2.6, esbuild. Зависимости нужны только для изменения и сборки исходников. Внешних библиотек с CDN при работе нет.

## Проверка

```text
npm test
```

Браузерная проверка использует установленный Google Chrome в Windows. На другой системе измените executablePath в tests/browser.mjs. Отчёт — info/TEST_RESULTS.md; настоящие скриншоты — evidence/.

## Данные

Записи хранятся в LocalStorage этого браузера на этом адресе сайта. Общей базы и авторизации нет. Другой посетитель не увидит ваши записи. Очистка браузера удаляет их; перед очисткой используйте JSON-копию. Данные локального адреса и публичного сайта не синхронизируются. Файлы резервных копий могут содержать введённые данные. Не используйте реальные персональные или конфиденциальные сведения на учебном стенде.
